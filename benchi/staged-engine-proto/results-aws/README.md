# AWS results (2026-10-12)

Early, non-gating read on a virtualized instance; not published. Read `RESULTS.md` first.

- `RESULTS.md`: setup, per-shape medians and floors, which differences exceed the floor, cost, cleanup.
- `AGGREGATE.md`, `COMPARISONS.md`, `HEALTH.md`: generated by `scripts/aggregate.py`, `scripts/pairs.py`,
  `scripts/health.py`.
- `sessions/<name>/`: `runs.csv` (every run, with start and end epoch), `summary.md`, `env.json`, `run.log`.
- `environment.txt` (instance, commits, binary SHA-256, CPU), `status.txt`, `bootstrap.log`, `vmstat.log`
  (5 s samples; `st` is steal, `wa` is iowait), `loadavg.log`.
- `manifest.json`: resource IDs created and deleted (account ID is the repository owner's own AWS account; no
  credential is in any file).
