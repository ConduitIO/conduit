# Drift check, 2026-10-14, laptop

**Indicative laptop numbers, not a gate result and not a performance claim.**

`../../matrix/drift.sh` asks how far `main` has moved from the commit the engine matrix
(`../20261014-laptop-matrix/`) built v1 and v2 from. Each session runs v1 and arch-v2 from both commits,
interleaved, every arm twice per round with its own A/A floor. `matrix.md` has every arm and comparison
(generated by `archv2-gate -rerender .`).

## Setup

- Same machine as the matrix: Apple M3 Max, Docker Desktop, not quiesced. Host load average 5 to 263 during
  the 1x1 session; 5 to 10 during the 4x4 session, the quietest of any laptop session so far.
- `base` is `c60003bb` (SHA-256 `1c8a913d...`), `main` is `461b2c42` (SHA-256 `f593e5d9...`), both with the
  bench patch. `main` was `461b2c42` when the binaries were built; it has moved since.
- 5 rounds, 8 s warmup, 25 s window (the gate requires 60 s). 23:04Z to 23:55Z.

## Results

| session | v1-base | v1-main | v2-base | v2-main | v1: main vs base | v2: main vs base |
| --- | --- | --- | --- | --- | --- | --- |
| 1x1 | 65074 ±137% | 66975 ±155% | 52732 ±156% | 92682 ±171% | +2.9% – | +75.8% suggestive |
| 4x4 | 30084 ±5.7% | 33557 ±5.5% | 44925 ±1.6% | 52363 ±6.4% | +11.5% resolved | +16.6% resolved |

Medians in records/s per sink with each arm's A/A floor. The 1x1 floors come from one disturbed round; the
typical A/A difference there is 1% to 3%, which is why its consistent deltas read as suggestive.

## What this says

- At 4x4, `main` is ahead of the matrix's base on both engines: v1 by about 11% and arch-v2 by about 17%,
  both resolved. At 1x1, arch-v2 on `main` leads its base by about 76% in every round, but one disturbed
  round makes that only suggestive.
- So the engine matrix, built from the base, understates current `main`, arch-v2 most. The prototype's lead
  over v2 in that matrix is a lead over an older arch-v2, and may shrink against `main`. The AWS run builds
  v1 and v2 from `main` for this reason.
- Like the matrix, this does not compare the prototype with `main`.
